# ClinicFlow – Smart Appointment Management

## Project Overview
ClinicFlow is a healthcare prototype designed to help manage appointments, assess patient no-show risk, and generate personalized appointment reminders.

## Features
- Dashboard showing appointment statistics
- Rule-based appointment no-show risk assessment
- Low, medium, and high risk categories
- Personalized appointment reminders
- Patient search and filtering
- CSV import and export
- Demo data persistence in the browser

## Technologies Used
- HTML
- CSS
- JavaScript
- AI-assisted development

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Important Note
This is a demonstration prototype using fictional patient data. Risk scores are based on predefined rules and are not medical predictions. Reminders are generated by the application and are not automatically sent to patients.
